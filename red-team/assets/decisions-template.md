# <gate>-<n> 처리 결과

## 의도 대조 — 리뷰어 `paraphrase` 를 `## 이 변경이 하려는 것` 과 대조한 결과
- 일치
- (또는) 불일치 — [축]: <무엇이 어긋났나> → context 수정, 재라운드 <gate>-<n+1>
- (한 줄만 남긴다. `불일치` 가 있으면 아래 절들은 비워 두고 다음 라운드 이관(`--next`)으로
  `## 이 변경이 하려는 것` 을 고친 뒤 돈다 — `measure_loop.py` 가 이 절을 센다)

## 반영 — 다음 컨텍스트의 `이미 반영된 지적` 이 된다
- [축] 파일:줄 요지 → 무엇을 했나 (커밋 해시)
- (봉인이 아니다 — 다음 라운드 리뷰어가 fix 가 닫혔는지 검증한다. 틀린 fix 는 다시 올라온다)

## 판정 완료 — 다음 컨텍스트의 `판정 완료` 가 된다 (재제기 금지)
- [축] 파일:줄 요지 → 실재하지 않음 / 의도된 동작 / 위험 수용 — 근거: <리뷰어가 열어 볼 수 있는
  코드 위치·커밋>
- 이미 닫힘: [축] 파일:줄 요지 → 직전 라운드 `반영` 의 fix 가 이미 닫았다 — 근거: <커밋·줄>
  (리뷰어가 닫힌 fix 를 다시 낸 경우. 접두 `이미 닫힘:` 을 그대로 쓴다 — `measure_loop.py` 가 센다)
- (근거 없는 항목은 적지 않는다 — 다시 올라오는 것이 맞다. fix 를 적용했으면 `반영` 이다)

## 후속 티켓 — 다음 컨텍스트의 `스코프 밖` 이 된다
- [축] 파일:줄 요지 → pre-existing. TICKET-XXX 신설 예정 / 원 티켓에 Relates

## 보류 — 사용자가 아직 결정하지 않음
- (없으면 비운다. 여기에 항목이 남아 있으면 라운드를 진행하지 않는다)

## 철회한 주장 — 다음 컨텍스트와 PR 회신의 근거가 된다
- [축] <이 라운드에 내가 냈다가 철회한 주장> → 철회 근거: <한 줄>
- (적지 않으면 다음 라운드나 리뷰 회신에서 같은 주장을 다시 꺼내 스스로 반박당한다.
  없으면 이 절을 지운다)

## 검증 구멍 — 적었으면 이 라운드에서 닫거나 명시 이관한다
- <구멍> → 이 라운드에 고침 / `후속 티켓` 이관 / `스코프 밖` 이관 (셋 중 하나)
- (신고만 남기면 다음 라운드 findings 로 돌아와 그 라운드가 그 한 건에 쓰인다.
  없으면 이 절을 지운다)

## 수렴 추이 — 라운드가 3회를 넘으면 적는다 (`references/long-gate.md`)
| 라운드 | P1 | P2 | 지적의 성격 |
|---|---:|---:|---|
| <gate>-<n> | 0 | 3 | `production` / `테스트 커버리지` / `주석·문서` 중 하나 |

**건수가 아니라 성격 전이를 읽는다** — `production → 테스트 커버리지 → 주석·문서` 로
옮겨가면 수렴이고 역행이 경고다. 건수만으로는 악화와 수렴이 갈리지 않는다.

## 다음 라운드의 판정 기준 — 3라운드 초과 + 성격이 production 을 벗어났으면 적는다
- 무엇을 보면 수렴인가: <예: 주석 지적 0~2건>
- 무엇을 보면 방법을 바꾸는가: <예: 5건 이상이면 라운드보다 사람의 전수 감사가 싸다>
- (사후에 세우는 기준은 그 라운드의 결과에 오염된다. 해당 없으면 이 절을 지운다)
